我是 Jrin，一个游走在会计凭证和代码逻辑之间的人。平时要么对着 Excel 和审计底稿发呆，要么对着终端敲命令、改 bug。这个博客就像我的数字手账本，记下了我在这两个世界里摸爬滚打的一点思考和笔记。

## 你可能会在这里看到什么？

- **审计/财务**  
  内部审计、研发费用怎么查、营销费用五步法……还有怎么读财报里的应收票据和货币资金。都是我自己踩过的坑和方法总结。
- **编程学习**  
  目前 Python 居多（列表、循环什么的），以后还会学更多。代码水平一般，但我会尽量写清楚。
- **AI 瞎聊**  
  大模型现在火得不行，我也在追，会写一些 LLM 的现状、模型对比、自己瞎试的体会。
- **生活里的小事**  
  读书笔记、偶尔的迷茫、深夜失眠的碎碎念。技术之外，人还得活着嘛。

> 没有固定栏目，想到啥写啥。你可能翻着翻着就遇到了一个计算广告费的逻辑，或者一段写给自己的鸡汤。
